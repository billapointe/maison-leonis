# Leonis Community — Brief page de vente

Ce fichier sert de mémoire de projet pour la page de vente **Leonis Community** (parfois noté « EONIS » dans les brouillons — nom officiel à utiliser : **Leonis Community**).

## Objectif

Créer une communauté grandissante d’entrepreneurs **francophones** qui valorisent leurs **relations d’affaires** et qui ont envie d’être **vus**. Chaque membre est **vu, compris et entendu**. **Valentine** rencontre chaque membre pour une conversation d’environ **20 minutes** afin d’apprendre à connaître ses axes (mission d’entreprise, valeurs, histoire personnelle, etc.).

## Lead magnet (visibilité)

Une fois par mois, Valentine passe une **journée complète** avec des entrepreneurs de la communauté pour apprendre à les connaître. Les conversations sont **enregistrées** ; des **clips** sont publiés en **réel** sur le compte **Instagram** pour mettre en valeur l’entrepreneur. Redirection constante vers **Leonis Community**.

## Direction créative & ressenti

L’ensemble doit évoquer une **soirée d’été élégante en plein air** : lumineux, un peu sauvage, **féminin sans fragilité**. Imagine du **mauve lavande** qui se dépose sur du **vert sauge**, comme des fleurs qui poussent dans une **cour de pierre**. Rien de corporate, rien de trop lisse — c’est beau parce que c’est **vivant**.

**Typographie** : un **serif** avec du caractère, presque **éditorial**, pour les grandes accroches ; un **sans-serif** propre et lisible pour le corps. **Beaucoup d’air** autour du contenu.

**Images** : les **photos de vraies personnes** portent le récit — pas de banque d’images générique.

**Émotion visée** : en arrivant sur la page, le visiteur se dit *« C’est exactement là que je veux être. »* Pas d’urgence agressive, **pas de rouge** comme levier principal. La **rareté** se lit dans la **qualité** de l’expérience, pas dans un compte à rebours ou une pression artificielle. Le mouvement vient des **photos** et du **texte**, pas d’**animations voyantes**.
